# 风言清最新一键隐藏

**云端卡密验证 · 环境隐藏 · 模块一键刷入**

适用于已取得 Root 权限的 Android 设备，通过 KernelSU 或 Magisk 自动安装模块。卡密验证、云端下载和安装进度集中在一个小体积 SH 文件中。

## 实测反馈

根据作者风言清的实测反馈，**和平精英、王者荣耀、三角洲行动**均有环境隐藏效果。此反馈来自作者，实际效果以设备、系统、模块和游戏版本为准。

## 功能

- 网页输入卡密，云端验证通过后开始下载、安装。
- 自动下载模块 ZIP，并调用 KernelSU / Magisk 安装命令刷入。
- 蓝奏下载、断点续传、异常重试和云端备用解析入口。
- 青色终端界面，显示流程阶段、下载进度、速度与安装耗时。
- 在手机上解压附带 SH，放入 `/data/adb`，供后续按需手动执行。

## 使用方法

1. 下载 **`风言清最新一键隐藏.sh`**，保存到手机的 `Download` 文件夹。
2. 在 MT 管理器中运行该 SH，授予 Root 权限；也可在终端运行：

   ```sh
   su -c 'sh "/sdcard/Download/风言清最新一键隐藏.sh"'
   ```

3. 脚本打开验证网页，在网页填写下面的卡密，再返回终端等待。
4. 验证通过后自动下载并安装，按界面提示完成后续操作。

下载中断时，已下载的缓存会保留；重新运行并验证后可继续下载。

## 刷入后的手动配置

安装成功后，**手动打开 Zygisk Next 的配置界面**，开启：

- **仅还原挂载**
- **匿名内存**

按已安装版本的界面保存配置；如管理器或模块提示重启，请手动重启手机。
